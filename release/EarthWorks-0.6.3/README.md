# EarthWorks 0.6.3

EarthWorks plans persistent terrain roads with multi-point curves, exact elevation and width control, Current/Result/Difference previews, and a six-stage networked project board.

Compatibility target: Valheim 1.0.12, Steam build 25253764, network version 40, Unity 6000.0.75f1, BepInExPack 5.4.2350, and Jotunn 2.30.0.

This patch fixes complete English/Russian localization coverage, verifies the Valheim 1.0 API contracts, and temporarily uses the vanilla Misc build category while Jotunn custom categories are unavailable.

Valheim was not launched during release preparation. This remains a development build pending controlled runtime acceptance.
