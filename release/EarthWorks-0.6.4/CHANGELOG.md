# Changelog

## 0.6.4

- Hardened project-board RPC authorization against the actual sender, distance, ownership, and ward access.
- Locked persisted enum IDs; added v1-v4 compatibility, v4 round-trip, and invalid-payload tests.
- Added embedded 227/227 EN/RU JSON catalogs with optional external overrides.
- Removed the unreachable staged editor path and split major responsibilities into focused source files.
- Reverified Valheim 1.0.12/Jotunn 2.30.0 interfaces, Harmony targets, and reflection contracts.
