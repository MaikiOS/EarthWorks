# EarthWorks 0.6.4

EarthWorks plans persistent terrain roads with multi-point curves, exact elevation and width control, Current/Result/Difference previews, and a six-stage networked project board.

Compatibility target: Valheim 1.0.12, Steam build 25253764, network version 40, Unity 6000.0.75f1, BepInExPack 5.4.2350, and Jotunn 2.30.0.

This patch hardens board RPC authority and persisted project data, keeps v1-v4 saves readable, moves EN/RU localization to embedded JSON catalogs with optional external overrides, and reorganizes the source for contributors. Valheim runtime acceptance remains pending.

Install `EarthWorks.dll` and `EarthWorks.Geometry.dll` together under `BepInEx/plugins`. EarthWorks must be present on the server and every participating client.

Source, documentation, roadmap, Pull Request rules, and permission contact: https://github.com/MaikiOS/EarthWorks

## Русский

EarthWorks создаёт постоянные проекты дорог: многоточечные кривые, точная высота и ширина, preview Current/Result/Difference и сетевая доска с шестью этапами.

Целевая совместимость: Valheim 1.0.12, Steam build 25253764, network version 40, Unity 6000.0.75f1, BepInExPack 5.4.2350 и Jotunn 2.30.0.

Установи `EarthWorks.dll` и `EarthWorks.Geometry.dll` вместе в `BepInEx/plugins`. Мод требуется на сервере и у всех участвующих клиентов.
