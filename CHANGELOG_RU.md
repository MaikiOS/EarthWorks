# Changelog

## В разработке

- Пока нет изменений.

## 0.6.5

- Зафиксирован успешный первичный игровой smoke английской локализации и Route; полная проверка каждого экрана/инструмента ещё открыта.
- Добавлены аудит terrain-совместимости с ATMC 1.4.8 и план сбора runtime-доказательств.
- Удалён устаревший paint offset на полклетки; запись использует точные штатные grid-координаты, сохранённые planner.
- При dirt/paving сохраняется текущий alpha paint-mask, чтобы не повреждать специальные terrain-данные, включая lava.
- Добавлены детерминированные paint-grid тесты четырёх углов зоны 65×65, border-координат и недопустимых индексов; portable suite теперь 26/26.
- Очистка травы по bounding-circle всего маршрута заменена обновлением вдоль sampled-коридора.
- Точный preview paint-core/bilinear feather и игровое доказательство seams/углов оставлены обязательными следующими gate.
- Заложено независимое направление собственных ручных terrain-инструментов: измеряемые квадратные footprint 2×2 и 4×4 м, начиная с Level и Paint.
- Двуязычное руководство для contributors дополнено конкретными задачами по тестам, локализации, совместимости, UX, документации и интеграции с другими модами.

## 0.6.4

- Мод пересобран и проверен против Valheim 1.0.12, Steam build 25253764, network version 40, Unity 6000.0.75f1, BepInExPack 5.4.2350 и последнего официального Jotunn 2.30.0.
- Усилена авторизация RPC проектной доски: запрос этапа проверяется по фактическому игроку-отправителю, дистанции, лабораторному персонажу, владельцу объекта и разрешениям ward.
- Зафиксированы числовые ID сериализуемых enum; добавлены исполняемые тесты чтения проектов v1-v4, round-trip v4, отклонения повреждённых данных и встроенной EN/RU локализации.
- Английские и русские строки перенесены в одинаковые JSON-каталоги, встроенные в DLL; поддержаны внешние overrides и автоматический аудит 227/227 токенов.
- Удалён недостижимый старый staged-editor workflow и 50 больше не используемых переводов.
- UI редактора, direct manipulation, camera patches/grid, создание доски, persistence и build settings разделены по понятным файлам без изменения публичного workflow.
- Добавлены стандартный solution, локальные overrides путей, deterministic build, portable CI, архитектурные документы и подробные правила contributions.
- Сохранена proprietary source-available лицензия: fork разрешён для Pull Request; повторное использование и распространение требуют предварительного письменного разрешения Ostrix.

## 0.6.3

- Сборка и API-аудит обновлены для Valheim 1.0.12, Steam build 25253764, network version 40, Unity 6000.0.75f1, BepInExPack 5.4.2350 и Jotunn 2.30.0.
- В изолированном тестовом профиле сохранено наше исправление регистрации terrain-операций Jotunn 2.30.0.
- Инструмент маршрута временно перенесён в штатную категорию `Misc`, пока Jotunn не восстановит custom categories для Valheim 1.0.
- Исправлено неверное разрешение `Drawing` в отсутствующие токены `state_drawing` и `controls_drawing`.
- Добавлен английский fallback для неразрешённых токенов Valheim.
- Полностью локализованы editor, сообщения камеры, ошибки планировщика/доски и результаты terrain-операций.
- Добавлен автоматический аудит 252 EN/RU ключей, плейсхолдеров, обращений к токенам, динамических состояний/этапов и смешанного языка.
- GitHub-документация переведена в English-first с русскими дублями; roadmap дополнен идеями TerrainTools для независимой реализации.

## 0.6.2

- Добавлен новый контракт Valheim 1.0 `Hoverable.GetHoverOffset()` для `RoadProjectBoard`.
- Сохранён hover offset исходной ванильной таблички при замене компонента `Sign` на проектную доску EarthWorks.
- Вызовы немедленного обновления Heightmap переведены на сигнатуру `Poke(int delayed, bool paintOnly)`.
- Reflection-вызовы сохранения terrain переведены на `TerrainComp.Save(bool)` с точным выбором overload.
- Проведён аудит используемых интерфейсов, Harmony targets, прямых и reflection-вызовов Valheim 1.0.7.
- Сборка выполнена против Valheim 1.0.7 build 25185596, BepInExPack 5.4.2350 и Jotunn 2.29.2.
- Версии `EarthWorks.dll` и `EarthWorks.Geometry.dll` обновлены до 0.6.2.0.
- Логика terrain, состояния проекта, редактора и этапов строительства намеренно не менялась.

## 0.6.1

- Геометрия маршрута, высота и ширина объединены в один редактор прямого управления.
- Добавлены X-Spline, B-Spline, Bezier и Corner.
- Добавлены независимая ширина сторон, четыре продольных профиля, endpoint fitting, точный preview и лабораторное выполнение проекта по этапам.
