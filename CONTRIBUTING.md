# Contributing to EarthWorks

Pull Requests are welcome for bug fixes, compatibility updates, tests, documentation, localization, and agreed roadmap work.

Before starting a large feature, open an Issue so its behavior and scope can be agreed first. Keep each Pull Request focused, explain what changed, and include the smallest relevant test or verification evidence.

By submitting a Pull Request, you agree to the contribution terms in [LICENSE.md](LICENSE.md). A GitHub fork may be used to prepare a contribution, but the license does not permit using EarthWorks code in another project without written permission from Ostrix.
