# Совместимость terrain и план проверки инструментов

[English (primary)](TERRAIN_COMPATIBILITY_AND_TEST_PLAN.md)

**Статус:** статический аудит завершён 13 сентября 2026 года. Runtime-доказательство ещё требуется.

Документ сравнивает EarthWorks 0.6.5 с проверенным поведением Valheim 1.0 в AdvancedTerrainModifiersCompatible 1.4.8. В EarthWorks переносятся только требования к поведению; GPL-код реализации не копируется.

## Что уже подтверждено в EarthWorks

- Высота использует штатные координаты `Heightmap.WorldToVertex`; пограничная вершина записывается во все совпадающие соседние Heightmaps.
- Перед изменением проверяется размер массивов `TerrainComp`: `(width + 1)²`.
- Ownership запрашивается и проверяется до записи; результат сохраняется через `TerrainComp.Save(false)` и обновляется через `Heightmap.Poke(0, false)`.
- При ошибке восстанавливаются height/paint массивы, счётчик операций, точка и радиус последней операции.
- Preview и выполнение используют один сохранённый план высот дороги.

## Статус 0.6.5 и оставшиеся paint-gates

1. **Paint-grid mapping — реализовано:** запись использует сохранённые planner штатные `GridX/GridZ`; устаревшего half-cell преобразования через `WorldToVertexMask` больше нет.
2. **Специальные каналы mask — реализовано:** dirt/paving перед сохранением копируют текущую `Heightmap.GetPaintMask(x, z).a` в новый цвет.
3. **Границы и углы chunks — добавлено автоматическое покрытие:** общий helper индекса `(width + 1)` проверяет все углы 65×65 и отклоняет внешние координаты. Реальное доказательство на двух и четырёх зонах ещё требуется.
4. **Видимая площадь текстуры:** текущая лента дороги не показывает настоящий paint core и bilinear feather. Они должны рассчитываться теми же границами, что и запись.
5. **Область растительности — реализовано, runtime tuning впереди:** обновление травы идёт по сохранённым preview samples с локальной шириной стороны плюс один метр; для старых записей есть centerline fallback.
6. **Совместная работа с ATMC:** ATMC глобально корректирует render UV Heightmap. EarthWorks обязан работать с этим patch и без него, не накладывая вторую конкурирующую глобальную коррекцию.

Сериализация `TerrainOp.Settings` из ATMC EarthWorks не нужна: EarthWorks сохраняет собственный точный план вершин. Правила восстановления старых `TerrainModifier` понадобятся при создании инструмента Restore.

## Порядок runtime-проверки

1. Зафиксировать screenshots и координаты нетронутой контрольной площадки.
2. Проверить только высоту в центре зоны, на границе двух зон и в углу четырёх зон.
3. В тех же местах отдельно проверить Dirt и Paved: core, feather, seams и соседние нетронутые texels.
4. Повторить на terrain с возможной lava в Ashlands и доказать сохранение alpha/специальных данных.
5. Сравнить Current, Result и Difference с применённой высотой и текстурой.
6. Выполнить save, reload, reconnect и проверку тех же клеток со второго клиента.
7. Повторить один раз с включённым ATMC 1.4.8 и один раз без него.
8. Принудительно вызвать ошибку batch и проверить полный rollback height, paint, метаданных операции и визуального результата.

Для каждого результата сохраняются мировые координаты, Heightmap indices, выбранное покрытие, screenshots before/preview/after/reload и соответствующий фрагмент `Player.log`.

## Проверка понятности интерфейса

До добавления новых режимов человек без знания исходников должен пройти все действия Route: найти инструмент в меню мотыги, поставить и завершить точки, открыть `F7`, выбрать и перетащить handles, задать точную высоту и ширину сторон, выбрать профиль/покрытие, понять validation, создать доску и пройти шесть стадий.

Для каждого действия фиксируются: намерение, видимый control, фактический результат, ошибочное действие и непонятная формулировка. Redesign должен дать короткий guided first route, постоянные подсказки, ясное состояние selection и легенду preview, а не ещё один слой скрытых hotkeys.

## Собственные ручные terrain-инструменты

После закрытия paint gate EarthWorks независимо реализует малые ручные операции:

- Raise, Lower, Smooth, Level, Slope, Dirt, Paved, Cultivate, Restore, Undo и Redo.
- Point, малый квадрат, большой квадрат, circle и line, привязанные штатным Valheim grid conversion.
- Кандидаты для квадратов: **логическое ядро 2×2 м** и **рабочая область 4×4 м**. Это размеры footprint, а не неоднозначный radius; точные texels и видимая фильтрация фиксируются только после измерения в игре.
- Preview показывает height vertices, paint core, bilinear feather, точные размеры, target height/delta и все копии в затронутых Heightmaps.
- Каждая операция использует server authority, wards, protected zones, разрешённый terrain range, transaction rollback и явную survival-стоимость.

Первый milestone — один квадратный Level и один квадратный Paint с общим протестированным grid-footprint helper. Остальные инструменты добавляются только после совпадения preview, save/reload, seams и multiplayer behavior этих двух.
