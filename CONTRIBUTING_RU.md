# Участие в разработке EarthWorks

[English (primary)](CONTRIBUTING.md)

Pull Requests приветствуются для исправлений, обновлений совместимости, тестов, документации, локализации и согласованных задач из roadmap.

Перед крупной функцией откройте Issue, чтобы заранее согласовать поведение и границы работы. Делайте каждый Pull Request узким, объясняйте изменение и прикладывайте минимальную достаточную проверку.

Отправляя Pull Request, вы соглашаетесь с условиями участия в [LICENSE.md](LICENSE.md). GitHub fork можно использовать для подготовки вклада, но лицензия не разрешает использовать код EarthWorks в другом проекте без письменного разрешения Ostrix.
